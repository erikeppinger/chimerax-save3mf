3MF export for 3D printing

Saves the scene as a 3MF file, with the colouring preserved as separate parts a slicer can assign to individual filaments.

save

save  filename.3mf  [ models model-spec ]  [ size mm ]  [ scale mm-per-Å ]  [ colors true|false ]  [ maxColors N ]  [ flavor prusa|bambu|generic ]  [ check true|false ]

The scene is written as displayed: whatever is shown in the graphics window is what gets exported, with hidden atoms, clipped surfaces and masked triangles left out. Instanced geometry such as atom spheres and bond cylinders is expanded into real triangles, and coincident vertices are merged so slicers see a connected mesh.

  • models – which models to export; the default is everything displayed.
  • size – scale so the longest edge of the model measures this many millimetres. This is usually what you want: molecules in Ångstroms are not printable sizes.
  • scale – millimetres per Ångstrom, default 1.0. Ignored if size is given.
  • colors – whether to split the model into one part per colour (default true). With false the whole model is a single part.
  • maxColors – merge down to at most this many parts. By default nothing is merged, so every distinct colour becomes its own part. See 3mf palette to decide the number.
  • flavor – which slicer the part structure is written for; see Slicer flavours below.
  • check – whether to report printability problems (default true).

The model is placed with its bounding box starting at the origin and its lowest point at z = 0. Coordinates are never negative, because a slicer reading a 3MF without its own placement data takes them literally and anything at negative x or y is off the build plate.

3mf palette

3mf palette  [ models model-spec ]  [ maxColors N ]

Reports the colour parts an export would produce, without writing anything. With no options it also shows what merging to each part count would cost, as colour swatches with the mean perceptual error (ΔE) in plain words, so the number of parts can be chosen before exporting: 

526 distinct colors across 814254 triangles
  merge to 4                       ΔE 21.7   strong shift
  merge to 8                       ΔE 9.3    clearly different
  merge to 16                      ΔE 4.7    slight shift
  no merge                         ΔE 0.0    526 parts, exactly as colored

With maxColors N it shows that exact palette instead, with the triangle count and area share of each part.

Colours are clustered in CIELAB rather than RGB, weighted by triangle area, so merging follows what the eye calls similar and a large surface is not merged away in favour of a few tiny ligand triangles. Each part keeps a colour that actually appears in the scene rather than a cluster average.

Slicer flavours

Slicers store multi-part models in incompatible ways and the geometry layout alone decides which one understands a file, so no single file works everywhere.

flavorLayoutUnderstood by
prusa (default) one mesh, parts as triangle ranges in Slic3r_PE_model.config PrusaSlicer
bambu component parts with model_settings.config Bambu Studio, OrcaSlicer
generic geometry and standard colour tags only any 3MF reader

Each part is written with an extruder already assigned, so a multi-tool printer needs no manual assignment at all. Parts are named after the drawing and the colour – for example 1a3n_A SES surface medium slate blue – so the slicer's part list says which chain is which.

Printability report

Unless check false is given, each export reports what a slicer will make of the geometry. Nothing is modified; the report only describes.

  • Disconnected pieces – whether the model is one body, or loose fragments around a solid one. A plain cartoon is often many separate ribbon segments that would print as loose pieces.
  • Not watertight – open or non-manifold edges. Overlapping shells from ball-and-stick styles are the usual cause, and slicers repair them unpredictably.
  • Sealed-in geometry – pieces fully inside another piece. Since ChimeraX shows cartoon by default, adding a surface leaves the ribbon sealed inside it, invisible in the print but still costing filament and time.
  • Thin features and extreme sizes – pieces below what a 0.4 mm nozzle can hold, or a model larger than most build plates.

To prepare a structure for printing – struts between disjoint pieces, thickened ribbons, solvent removal – use the NIH 3D print presets bundle. This bundle only measures and reports.
